ABOUT DRIVENEST

A student-built rental project, rebuilt for today.

DriveNest started as a collaborative hackathon-era Django project. This refreshed version focuses on cleaner engineering, safer booking logic and a much more usable interface.

WHAT MATTERS

Less friction. Better fundamentals.

The goal isn't to pretend this is a production rental marketplace. It is to show a solid Django application with authentication, database-backed vehicles, server-side booking calculations and an admin workflow.

Database-backed fleetVehicle names, descriptions, images and prices come from Django models.
Account-based bookingsAuthenticated users can view their own confirmed rentals.
Server-side totalsRental totals are recalculated on the server before a booking is saved.
DjangoBackend framework
SQLiteLocal development database
